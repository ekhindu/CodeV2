# ekhindu.org (Milestone 1)
1. Upload ALL files (including the hidden .github folder) to your GitHub repo's main branch.
2. Settings > Pages > Source: GitHub Actions. Custom domain: ekhindu.org.
3. Edit public/admin/config.yml: replace YOUR-GITHUB-USERNAME/YOUR-REPO.
4. Set youtubeChannelId and AdSense IDs in src/data/settings.json (or via /admin).
5. Panchang data in src/data/panchang is SAMPLE ONLY. Replace with verified data before launch.
